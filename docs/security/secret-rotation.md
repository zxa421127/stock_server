# 密钥与Token轮换

如果 `.env`、数据库或完整API Token曾进入聊天、邮件、网盘或共享ZIP，应视为已经泄露。

1. 维护窗口内停止Web和后台Worker。
2. 备份数据库并限制备份访问权限。
3. 生成新的 `SECRET_KEY`、管理员密码哈希、管理员代理共享密钥、API Token哈希密钥和审计密钥。
4. `SECRET_KEY`变化会使所有现有Session失效。
5. `API_TOKEN_HASH_SECRET`不能直接更换后继续使用旧摘要；应先要求所有用户轮换Token，或编写双密钥过渡迁移。不要在没有过渡方案时直接替换。
6. 如管理员设备证书或PFX密码外泄，立即撤销对应证书并签发新证书。
7. 对已经外泄的用户Token逐个执行轮换。
8. 重启服务并运行生产预检与接口验收。
9. 删除旧密钥在密码管理器、CI变量和服务器中的所有副本。
